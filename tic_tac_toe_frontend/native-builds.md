# Native Builds Information

## Development Mode
This project uses Expo's managed workflow and is designed to be developed and tested using Expo Go.

## Native Build Notes
- Native builds (Android/iOS) are NOT required for development
- Gradle errors can be safely ignored
- Use `npm start` and test in Expo Go

## If Native Builds Are Needed Later
If native builds are required in the future:
1. Use EAS Build (Expo Application Services)
2. Configure build profiles in eas.json
3. Follow Expo's native build documentation

For now:
✅ Use Expo Go
✅ Ignore native build errors
✅ Focus on app functionality
